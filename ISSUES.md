# Known Inconsistencies & Open Questions

Each item below was found during the codebase audit and awaits a product/design decision:

1. **Modal & drawer backdrop opacity variations:** `ConfirmDialog`, `ExportCourseDialog`, `ImportCourseDialog`, `SearchModal`, and the `CoursePage` backup modal use `bg-black/50 dark:bg-black/70`; `AssessmentBuilderModal` uses `bg-black/50 dark:bg-black/75`; `AssessmentRunnerModal` and `MaterialViewerModal` use `bg-black/60 dark:bg-black/75`; `DrawerShell` uses `bg-black/40 dark:bg-black/60`. *Decision needed:* Standardize all modal backdrops to one token pair or keep heavier backdrops on fullscreen players/builders?
2. **Container max-width variations:** `Navbar`, `CatalogPage`, `CourseHeader`, `ProgressStrip`, `CourseEditorPage`, and `EditorStickyBar` use `max-w-5xl`; `CoursePage` and `DataFormatsPage` use `max-w-6xl`; `ChecklistView` uses `max-w-4xl`. *Decision needed:* Keep per-layout widths (`4xl` checklist, `5xl` standard, `6xl` canvas/sidebar) as the intentional standard?
3. **`AppShell` wrapper background classes:** `src/App.tsx` wraps routes in `bg-gray-50 dark:bg-slate-950`, which is visually overridden by each page's `<main className="... bg-slate-50 dark:bg-[#0b0f17]">`. *Decision needed:* Align `App.tsx` wrapper classes with `bg-slate-50 dark:bg-[#0b0f17]`?
4. **Duplicated SVG status hex literals:** `ROADMAP_COLORS` in `src/lib/theme.ts` defines status and hover hex colors that are also written as raw hex literals in `src/index.css` and `CoursePage.tsx` (`handleDownloadSvg`). *Decision needed:* Generate the inline export stylesheet from `ROADMAP_COLORS` / CSS variables or keep them separate?
5. **Drawer tab names & material count phrasing:** `ChapterDrawer` labels tabs `"Materials"` (leaf chapter) / `"Overview"` (multi-lesson) and `"Notes"`, while `LessonDrawer` uses `"Resources"` and `"Study Notes"`. `LessonEditorCard` shows `"{N} res"` while `ChecklistView` formats `"1 material"` / `"2 materials"`. *Decision needed:* Standardize drawer tab labels to `"Materials"` & `"Notes"` across both drawers, or keep the current labels?
6. **Modal focus trap, fullscreen viewport unit & SVG keyboard shortcuts:** Modals and `DrawerShell` do not trap `Tab` focus or restore focus on close; `MaterialViewerModal` fullscreen uses `h-screen w-screen` instead of `h-dvh`; `CourseTreeCanvas` `onKeyDown` handles `Enter`/`Space` to open a node but does not mirror `Shift+Click` or keyboard context menu. *Decision needed:* Add focus trapping, `h-dvh`, and keyboard quick-status shortcuts in a future accessibility pass?
7. **Unused / test-only helpers:** `getAllLessons`, `getAllLessonIds`, and `findLessonWithChapter` in `src/data/validateCourse.ts`, plus `getCourse` and `resetCatalog` aliases on `CourseContextValue` in `src/store/useCourseStore.tsx`, are unused in runtime components. *Decision needed:* Remove unused aliases/helpers or keep them for test convenience?
8. **Duplicate export envelope interfaces:** `CourseExportEnvelope` and `CourseAttachment` in `src/lib/courseExchange.ts` are re-declared in `src/data/exampleCourseExport.ts`. *Decision needed:* Import the shared types from `src/lib/courseExchange.ts` in `exampleCourseExport.ts`?
9. **Viewer vs. `openStoredFile` text extension list:** `MaterialViewerModal` (`TEXT_EXTENSIONS`) previews extra text/config extensions (`.markdown`, `.jsonl`, `.mjs`, `.cjs`, `.cc`, `.yaml`, `.yml`, `.toml`, `.xml`, `.css`) not listed in `TEXT_CODE_EXTENSIONS` in `src/lib/fileStore.ts`. *Decision needed:* Share one unified text/code extension set in `src/lib/fileStore.ts`?
10. **`AssessmentSchema` vs. `DataFormatsPage` numeric bounds:** `AssessmentSchema` (`src/types/course.ts`) validates `timeLimitMinutes` as any positive integer and `passingScorePercent` as any number `0..100`, whereas `DataFormatsPage.tsx` and `LLM_EXAM_PROMPT` document `int 1..300` and `int 0..100`. *Decision needed:* Tighten `AssessmentSchema` to `.int().min(1).max(300)` and `.int().min(0).max(100)` or relax the docs?
11. **Question header `imageUrl` protocol vs. UI copy:** `AssessmentQuestionHeaderSchema` accepts both `http://` and `https://`, while UI labels in `AssessmentBuilderModal` and `DataFormatsPage` say `https://`. *Decision needed:* Restrict schema to `https://` or update UI copy to `http(s)://`?
12. **`.catch('Preparatory')` fallback on `department`:** `CourseTreeSchema` in `src/types/course.ts` uses `.catch('Preparatory')` when `department` is missing or under 2 chars, as documented on `DataFormatsPage`. *Decision needed:* Keep this default fallback for LLM/import convenience or require explicit validation failure under strict schema rules?
13. **Repository `StorageLike` adapter asymmetry:** `createLocalProgressRepository` (`src/lib/storage/localRepositories.ts`) checks `window.localStorage` directly rather than using `resolveStorage`, and `useCourseStore.tsx` builds no-op `getItem`/`removeItem` stubs when calling `userRepo.saveCourses`. *Decision needed:* Clean up the `StorageLike` helper adapters across `localRepositories.ts` and `useCourseStore.tsx`?
14. **One-shot IndexedDB garbage collection:** `src/App.tsx` runs `garbageCollectFiles` once per app load (`gcRanRef`), leaving files deleted mid-session in IndexedDB until the next reload on a non-editor route. *Decision needed:* Also trigger `garbageCollectFiles` after course save/delete, or keep startup-only GC?
15. **`SearchModal` query fields & missing `README.md`:** `SearchModal.tsx` does not match against `course.description` or resource titles (though `DataFormatsPage.tsx` states `course.description` is shown in search), and the repository root has no `README.md`. *Decision needed:* Include `course.description` in `SearchModal` matching (or update `DataFormatsPage` copy) and add a root `README.md`?
