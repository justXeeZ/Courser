# Courser — Specification Index

**Courser** (`c.`) is a local-first web application for structuring and studying college courses as interactive chapter-and-lesson roadmaps with study notes, uploaded or embedded materials, interactive LaTeX exams/assignments, and portable JSON import/export—all stored locally in the browser without a server account.

- [`DESIGN.md`](./DESIGN.md) — Visual design intent, theme rules, reusable components, layout patterns, accessibility, and new-page checklist.
- [`DATA_MODEL.md`](./DATA_MODEL.md) — Schema invariants, ID/rekeying rules, progress math, immutable storage/export identifiers, and non-goals.
- [`CHANGE_PROTOCOL.md`](./CHANGE_PROTOCOL.md) — Scaled checklist for keeping code, tests, seed data, and documentation in sync.
