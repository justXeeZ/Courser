# Courser

Local-first interactive course roadmaps: chapter-and-lesson study trees, progress tracking, and exam packs, stored in your browser.

Live: https://justXeeZ.github.io/Courser/

## Develop

```
npm install
npm run dev
npm run typecheck
npm test
npm run lint
npm run build
```

## Deploy (GitHub Pages)

The build uses base path `/Courser/` (override with `VITE_BASE_PATH`). `public/404.html` redirects deep links to the SPA. Publish `dist/` to GitHub Pages.
