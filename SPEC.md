# College Course Trees — Specification Index

**College Course Trees** is a local-first web application for structuring and studying college courses as interactive chapter-and-lesson roadmaps with study notes, uploaded or embedded materials, interactive LaTeX exams/assignments, and portable JSON import/export—all stored locally in the browser without a server account.
